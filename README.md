# EX No.5.1.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:24-11-2026

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

1.Open Fusion 360.

2.Create a new file.

3.Select Create Sketch.

<img width="320" height="506" alt="Screenshot 2026-11-15 124347" src="https://github.com/user-attachments/assets/9275aa61-cefa-48d2-afcc-11a02c7d398c" />

4.Choose the required plane.

5.Draw the shape using Circle,Line and Trim tools.

6.Click Finish Sketch.

<img width="256" height="172" alt="Screenshot 2026-11-15 124609" src="https://github.com/user-attachments/assets/c6521d80-c242-4e75-88de-f8680c15ce5e" />

7.Use Extrude to create a 3D model.

<img width="452" height="560" alt="Screenshot 2026-11-15 133419" src="https://github.com/user-attachments/assets/2232f10c-5e0b-4ea9-80d3-fa426a0fdde3" />

8.Switch to Drawing Mode.

<img width="336" height="412" alt="Screenshot 2026-11-15 124628" src="https://github.com/user-attachments/assets/5d3f9ad9-9829-4c8e-8645-f6a8eeea98d8" />

9.Select Base View and place the model.

10.Use Projected View to create orthograpic views.

## RESULT:
Thus, the given 3D model is converted into orthographic view.
